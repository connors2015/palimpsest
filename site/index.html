The opening

Nobody has closed the loop.

Every decentralized-AI network to date pays its contributors in token inflation and hopes revenue arrives later. The field's largest runs a 20–40× emissions-to-revenue subsidy — an inflation machine wearing a flywheel costume.

No network on earth currently pays training rewards out of inference income. That crown is unclaimed. Claiming it does not require the world's best model — only a model whose users pay more than its training costs. Palimpsest is built to reach that crossover, and to be the first to prove it.

The gap

Transformers solved cooperative machine cognition. Bitcoin solved adversarial bookkeeping. Neither solved a self-funding, openly-owned model that improves because improving it pays.

The flywheel

Better model → more paid inference → more revenue to training → better model. Rewards anchored to fees the chain actually earns, with bootstrap issuance on a hard sunset.

Mechanism

The model is the ledger.

Every competitor keeps the incentive layer on-chain and the model in someone's bucket — Cloudflare, HuggingFace, S3. Their "decentralized" model has a landlord. Ours has a genesis block.

In Palimpsest a block is one optimizer step. A transaction is a signed gradient update; the block header commits a Merkle root over the weights; the state transition applies the aggregated update deterministically. The block cadence is exactly the synchronization rhythm that made internet-scale training feasible in the first place — the two fields were describing one mechanism.

Consensus over improvement, not just order. A gradient update is included only if a commit-reveal committee measures that it helps — the mechanism that kills the weight-copying attack which hollowed out the incumbent network.

Serve a model too large to hold in memory. Experts are paged; a query loads only the few it routes to and proves them with Merkle inclusion proofs. Serving cost is O(k), not O(model).

Flywheel

The full loop runs end to end. Miners train → a committee scores → the block applies deterministically → inference is served with attested receipts → fees pay the miners.

Consensus

Commit-reveal scoring defeats the Bittensor attacks. In simulation, weight-copying and sub-majority collusion are both negative expected value.

Async

Real permissionless dynamics. Heterogeneous miners submit whenever they finish; stale work is scored against the live head and discounted — the model still converges.

Serving

Attested sparse inference. A verifier holding only the pages a query used recomputes the answer and rejects tampering, under-loading, and forged outputs.

Systems

Runs across real processes. Miners as separate OS processes over sockets produce a byte-identical chain; state persists to disk and fast-syncs from checkpoints.

Why now

The physics objection is dead.

Five years ago, training over the open internet was fantasy. Today it is demonstrated: a 72-billion-parameter model trained by 70+ anonymous nodes over commodity internet; a 40B model trained to 20 trillion tokens coordinated on-chain; 100B-class runs over ordinary 1 Gbps links. What remains unsolved is the economics and the settlement — which is exactly where we build.

The window is real but not open forever. Interop and agent-payment standards are laying the rails now; the settlement layer on top is the obvious next thing, and whoever proves the revenue loop first owns the existence proof everyone else is still promising.

What could kill this.

The founding memo's doctrine is a first-principles limits section written by us before a reviewer writes it for us.

Detection

The security model assumes probes catch poisoning that also improves loss. If a stealthy backdoor beats them cheaply, the story weakens. This is what we test next.

Scale

Everything proven so far is toy scale. The 2–3× compute handicap and convergence at billions of parameters are real, and only a funded devnet answers them.

Demand

The bootstrap economics close under modeled demand. A vertical clearing the revenue threshold must be found and signed, not assumed.

Reflexivity

The supply-side moat runs on token value; the durable moats are attestation, freshness, and provenance — the ones that survive a bear.
